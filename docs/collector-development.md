# 通用真实采集适配器 开发中

2026-11-12：已后台启动既有隔离Chrome，但初始BOSS页出现安全验证；只读检测后立即停止，未执行搜索/岗位采集，专用浏览器已关闭。现场结果为平台验证暂停，不能计为真实采集验收通过。继续推进可独立验证部分，现有合成Release不包含此功能。

Node 22+，无npm依赖，使用全局fetch/WebSocket。必须已有用户自己登录的隔离Chrome CDP，端口仅监听本机；不读取日常浏览器配置，不绕过验证、不导出Cookie、不发起沟通。启动隔离Chrome及登录尚未产品化接入网页，不能称开箱可用。

```text
node scripts/collect_jobs.mjs --config examples/collector-config.json --output data/private-market/run-001 --endpoint http://127.0.0.1:9333
```

示例配置仅为通用业务/数据检索，并非个人方向判断；用户需根据已确认条件设置城市及关键词。默认目标100不同平台公司，上限200岗位详情；不含翻页/滚动，关键词首屏不足时明确覆盖不足，不能声称全市场覆盖。只有一个BOSS标签可自动选择，否则需显式--tab-id；不使用固定本机tab ID。

checkpoint保存配置hash、搜索/岗位/公司原文、时间、失败代码和未评审状态。同输出不能暗改配置；已成功岗位去重，同公司不同岗位保留。平台验证/登录/连接超时停止，当前未完成岗位允许用户修复环境后续跑；普通页面失败记录并跳过，不无限自动重试。不要同时操作同一个标签或并发写同一输出目录。

仅从岗位“公司基本信息”明确容器获取公司链接，推荐链接、多个不同主体、找不到容器均不绑定公司；匿名岗位保留，但不计为已知主体覆盖。平台路径去重不是法定主体核验，集团关系还需后续研究。DOM选择器未经当前实站验证，可能产生未知或覆盖不足，应诊断后修正，不靠降低身份判断标准凑100家。

纯策略测试：`node scripts/test_job_collector.mjs`，覆盖URL范围、配置不可暗改、等待下限、验证停止、匿名隔离与一公司多岗位去重。新增`node scripts/test_collector_protocol.mjs`使用标准库HTTP/WebSocket合成协议服务器，验证3岗位/2公司、恢复去重、导航前登录/验证停止、断线保存；不访问真实站点，也不验证DOM选择器、有效岗位或真实用户登录。

已将入口检查移至首次导航之前，连接失败也记录暂停，不以自动重试绕过验证。阶段4仍需用户可用登录环境中的小批现场核对、原文与公司身份人工检查，再接工作区。无需为现场受限假装完成，也不将协议测试成功冒充真实采集。
