# 本轮结果：汇总、选择、排序与私人导出

main新增人工辅助结果闭环，不属于旧合成Release。入口为本地工作区第9节。没有自动模型推荐，没有总匹配分，也不自动执行收藏、沟通或投递。

## 执行顺序

1. 保存简历事实及岗位检查点，明确本轮预筛条件。先对重点岗位完成第7节片段人工复核；第8节公司研究可以未知，不强迫上市或财报齐全。
2. 到第9节选择查看顺序并生成汇总。系统读取当前候选事实、最新岗位检查点，以及每个岗位／公司的最新复核。不会只取最后一个岗位的复核，也不会回退到旧的正向结论。
3. 查看覆盖数、公司人数规模、岗位条件、能力复核范围、公司研究、三项沟通提纲及原文依据。目标为100个不同平台公司标识；匿名岗位不凑公司数，同公司多个岗位不重复计覆盖。达到100仅表示数量覆盖，不表示100家深评完成。
4. 逐个岗位明确选择并填写理由。人工优选最多10家、人工候选最多10家；同公司改选会撤回该公司之前的名单岗位，保留历史。未复核或无已确认经历交集不能入名单；硬条件未知只能保留候选，明确不符只能保留取舍或不考虑。缺额不填充，不自动放宽条件。
5. 使用“向前显示／向后显示”保存本人本轮展示顺序。它与系统参考顺序分别保存，不等于长期偏好，也不改变硬条件或复核状态。改变查看依据须重新生成，旧选择不自动迁移。当前尚不自动解释自然语言排序需求。
6. 明确确认私人导出范围后下载HTML或JSON。HTML可离线阅读，展开查看条件和证据；JSON保留完整结构和版本关联。生成导出内容／发起浏览器下载，不等于文件已实际保存，请自行核对文件。

## 判断与展示

默认顺序先看已披露硬条件，再看是否完成片段人工复核，已知人工重大风险后置提示。待遇顺序比较薪资／休息制度的待确认项，仍不抵消硬条件。公司维度只支持已知重大风险提示，**尚未实现公司成长排序**，不冒称前景排名。未知财报不排除公司，不把规模越大当作越好。

同档允许并列；内部稳定ID仅用于复现，不表达精确优劣。优选／候选是使用者人工确认的名单，不是系统已证明的“最优20家”。岗位片段最多60项，已全部复核仍不保证整份JD被正确理解；须人工检查原文拆分和关键职责遗漏。

沟通提纲固定三项：

- **该强调的真实经历**：只使用当前已确认事实及岗位人工复核中的直接／部分交集，同时保留原文和理由。不根据关键词推造新技能。
- **最需要核实的问题**：针对薪资构成、双休、学历、地点、能力尚未复核和用工主体提出核实问题。它是提纲，不是已确认的公司答复。
- **双方可能不匹配之处**：分别列明硬条件披露不符、能力部分相关或证据缺口；未知不解释为求职者不会。

规模字段只从同公司页面的介绍／热招前头部提取人数区间并保留引用；找不到或多值冲突则显示未知／冲突，不借用推荐公司的数字。暂不自动合并不同平台标识的同一法定主体。

条件差异共性按“维度＋未知／冲突／明确不符”统计**岗位数**，不能冒称这些公司全部被排除；本人排除理由单独列出，尚未做语义聚类。另列单项取舍假设：只有其余配置条件均披露符合，才统计忽略该项后可能新增的条件符合公司；未知不当符合，已有符合岗位的公司不重复计新增。它不包含能力合适或本人愿意的承诺。用户据此决定后续是否调整条件，本轮不会悄悄改条件。追加采集仍应由采集器沿原轮次断点去重，不由导出模块隐式补抓。

## 版本、隐私与后续动作

候选事实确认、简历版本、岗位检查点、能力复核或公司研究变化，旧报告标过期；禁止基于它继续选择、重排或导出，需要重新汇总。每次选择和重排都是新版本，旧版本不覆盖。引用hash与关联用于追溯和识别变化，不是防恶意篡改的签名。

HTML和JSON均是**私人材料**，可能含可识别的完整工作经历片段、公司、时间和选择理由；不因为去掉姓名就匿名。全部留在本机忽略目录，不进入开源包，没有自动公开分享入口。HTML对输入转义、禁止脚本和远程资源；岗位链接只定位原岗位，打开后还须刷新核实。当前没有收藏／沟通成功记录，因此只能说明本系统未执行动作，不能宣称其他渠道未投递。

模块入口为`result_report.py`，API包括`result-generate`、`result-choose`、`result-reorder`和`result-export`；与本地工作区使用相同来源和令牌保护。脚本不联网，测试均用合成材料。HTTP检查覆盖显式确认、旧版本和证据变化保护；Chrome检查页面选择、重载及HTML／JSON实际下载。100家公司用例只验证合成覆盖计数，不证明真实市场筛选效果。新工作区仍需Windows／macOS完整验收和真实漏选检查。

## 本阶段验收记录（2026-11-12）

顺序：当前证据汇总及指纹 → 每岗位／公司最新复核归并 → 人数规模引用 → 同档参考顺序与个人顺序分离 → 10＋10人工选择及同公司去重 → 三项沟通提纲 → 条件差异统计与单项取舍假设 → 私人HTML／JSON导出 → 证据变化拦截 → 回归、浏览器下载和干净目录验证。
