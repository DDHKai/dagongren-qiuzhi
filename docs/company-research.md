# 公司财报：固定信源、原文留证与人工复核

这是main上的真实工作区新增基础能力，不属于旧合成实验Release。它下载用户指定的官方公开文档，保存hash与页段原文，辅助人工复核；**尚未自动搜索证券身份、发现最新报告、检查更正公告或给出公司成长结论**。未上市、身份不明、下载失败均保留未知，不因此排除岗位。

## 固定信源

配置唯一入口为[financial-sources.json](../config/financial-sources.json)：A股[巨潮资讯](https://www.cninfo.com.cn/new/index)、港股[披露易](https://www.hkexnews.hk/index_c.htm)、美股[SEC EDGAR](https://www.sec.gov/search-filings)。HTTPS域名和重定向逐次校验，最多3次；不静默改用聚合站、媒体或搜索摘要。官网IR只能辅助定位，当前不能替代固定源。其他市场不自动研究。

先在相应入口人工核对证券代码／CIK、发行人法定全称、报告期与更正／重述，再填写原文链接。只下载PDF或UTF-8 HTML；当前30秒请求超时、25MB文档和400页上限。PDF需安装[可选依赖](resume-document.md)。扫描件、其他编码或失败响应不被当作有效证据。美股请求须在本机设置`DAGONGREN_SEC_USER_AGENT`，内容含本人联系邮箱，不使用虚构身份；该值不写入报告，不公开提交。未保证所有市场文档格式兼容。

## 工作区顺序

1. 启动`start-windows.bat --workspace`，macOS使用`sh ./start-macos.command --workspace`。先保存简历与岗位预筛，再到第8节选择本轮公司，查看公司原文。没有公司页身份的匿名岗位保留未知。
2. 未上市或关系不明，可直接保存未知。已定位财报时填写市场、证券代码、发行人和招聘主体全称、主体关系、报告类型、期间、披露日期、检查日期、币种、单位、合并口径与审计状态。招聘主体须在当前公司页中有精确原文。母公司与招聘子公司不得当作同一主体。
3. 明确允许请求官方原文后点击保存。服务只向固定官方域名发送文档请求，不发送简历、求职条件或BOSS登录态。原始文档、提取结果、请求时间、最终URL和hash都保留在本机私有记录。下载成功仍为待复核。
4. 在本机打开该记录版本中的`source.pdf`／`source.html`对照原页。选页段填写发行人和期间原文，可选填写指标及风险判断；母子关系另需引用该财报中的关系证据。如果该报告不包含关系证据，保持关系未核实，不强行确认。
5. 每次复核为新版本，不覆盖原文或历史。复核按本次完整填写的内容保存，不自动继承上次指标。当前页面仅展示最近一次公司研究，所有历史仍在本机；跨公司汇总留待结果闭环阶段接入。岗位检查点更新会阻止沿用旧公司证据复核，必须重新核对。

## 判断边界

指标支持经营现金流、营业收入、净利润、应收款、现金及等价物、受限现金、明确披露的可用现金、短期有息债务及有息债务。数值须为引用中的原始数字，禁止隐式换算；币种、单位、合并口径和期末日期必须与文档元数据一致。经营现金流等流量使用累计起止日，余额按期末日。不自动将货币资金当作可用现金，也不默认受限资金可偿债。

只有显式可用现金和短期有息债务都存在、同口径且债务大于0时，才计算两者比值；该比值不自动触发统一风险阈值。暂无跨期现金回收趋势、债务到期结构建模或审计意见自动解读。股价与市值不作为雇主质量分。

风险可人工区分普通波动、需关注、明确重大风险，每项须给理由及精确引用。重大风险应突出保留，但不是系统自动审计结论。引用存在只证明文字位置，不证明所选指标、列、期间或因果解释正确。元数据及原文hash防意外修改，不是防恶意篡改的数字签名。最新性、关系、期间和单位的语义仍由复核人负责。

成长前景维持未知；不生成总匹配分或大公司排名。公司规模、待遇、岗位能力与行业机会仍需分别研究，不能用财报高分抵消硬条件。无法确认不能标作“公司有风险”或“已核实安全”。

## 脚本与产物

命令行入口：

```text
python scripts/company_research.py capture --metadata data/private-research/metadata.json --output data/private-research/capture-001
python scripts/company_research.py review --folder data/private-research/capture-001 --review data/private-research/review.json --output data/private-research/review-001.json
```

元数据字段与页面一致，机器键名见`company_research.metadata`；证券标识CN为6位、HK为5位、US为10位CIK。复核载荷含`reviewerConfirmed`、`identityEvidence`、`periodEvidence`、可选`relationshipEvidence`、`metrics`和`finding`；引用一律为`{unitId, quote}`，数值使用字符串。API测试中有完整合成示例，测试不会请求网络。所有真实产物保持本地忽略，不进入开源包。

自动检查覆盖域名、主体/日期约束、失败未知、hash、精确引用、单位、短债比值、显式复核、旧版本及过期市场证据。Chrome测试覆盖未知公司的保存与重载；真实官方文档试跑只认证下载及提取链，不认证财务分析。新工作区仍需双系统完整验收。
