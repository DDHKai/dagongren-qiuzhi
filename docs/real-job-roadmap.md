## 阶段1使用

Python 3.10+，只调用标准库和项目已有事实模块，无网络、模型或外部动作。先用合成样例：

```text
python scripts/resume_workspace.py create --resume examples/synthetic-resume.json --conditions examples/synthetic-conditions.json --output data/private-intakes/example-001
```

真实使用将resume参数换为自己的UTF-8 .txt或符合样例的.json路径，输出必须为新空目录，建议置于data/private-intakes下。TXT只保留任务行，不推断公司/职位/年限；JSON保留已有字段，目前仅从experiences中的responsibilitiesRaw和achievementsRaw提取逐行事实。PDF/DOCX暂不支持，不能改扩展名冒充支持。

输出source.bin、resume.json、facts.json、conditions.json、manifest.json及本地盐。这些全部是私有材料，不能提交或公开分享。无加密与账号隔离；共用电脑请按自身要求控制文件权限，项目不承诺绝对保密。条件格式must/prefer/ignore均为字符串列表，尚不自动解释自然语言约束，条件状态仍待审阅。

查看facts.json确认原文，选择实际核对过的ID执行：

```text
python scripts/resume_workspace.py confirm --output data/private-intakes/example-001 --fact-id fact_替换成实际ID
```

可重复--fact-id，但没有“全部默认确认”。确认只表示本人认可来源陈述，不代表学历、雇佣关系或业绩已由第三方核实。原文改变时创建新版本，不覆盖原输入。跨设备事实ID不保证一致，本地盐不可公开。

test_resume_workspace.py覆盖输入/显式确认、拒绝覆盖、事实篡改、条件冲突、TXT不捏造公司。统一发布检查同时运行这些测试。不涉及真实岗位效果、复杂文档解析或真实用户体验，不能依据此阶段宣称已可求职。
