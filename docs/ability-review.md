# 岗位能力证据对照与人工复核

main开发能力，尚未纳入既有合成实验Release。当前是离线检索＋人工复核工作流，不是自动AI语义匹配。没有模型调用、费用、联网搜索或总匹配分；不能用本阶段完成度声称自动推荐已实现。

## 使用

以--workspace启动，导入并校对简历，逐项确认事实；上传采集检查点并完成条件预筛。第7节选岗位生成草稿，再逐项检查岗位片段、检索线索、事实引用、结论与理由。

职位描述以原文行切成最多60片段，仅保留不少于8字符的行；短标签和换行可能使要求遗漏或拆散。因此片段不是自动识别的完整职责，原文顺序不是优先级。先人工核对上下文，遇无法判断的片段选尚不明确并说明原因，不能以全部片段已处理声称全JD覆盖。

相关事实按词项检索，显示共同词但不评分、不自动选择证据。命中AI不代表RAG/编程，未命中也不代表没有能力。正向结论只允许使用本人明确确认的事实；确认仍不是雇主、学历或业绩的第三方验证。

结论：有直接证据、部分相关/可迁移、尚不明确、缺少简历证据。任何保存项都需理由；全部原文片段完成后显示已人工复核，否则仅部分复核。草稿、复核各存新版本；旧稿不覆盖。算法/工具/年限词保护要求直接引文，否则不能保存为完整支持，可选部分/未知说明差距。此保护仅有限词表与原文检查，不保证语义完整或年限换算正确；不能靠它认证专业能力。

简历新版本、事实确认变化或新市场证据都会使旧报告失效，须重新生成；不能把旧结论静默迁到新证据。页面默认打开最新报告，历史文件仍在私有目录。

## 方向探索

仅用已确认任务提供少量预设方向假设（投放/运营分析/业务AI/供应链/客户成功等），列事实ID来源。它不是全职业覆盖、市场增长判断或职业定位结论。用户选择愿意、不考虑、暂不确定，反馈只对当前报告生效，不改变长期画像、不启动搜索。没有已确认线索时不生成方向。

## 边界与验证

语义判断由本轮用户/人工复核者作出，系统仅校验结构、引用及上下文；理由本身不被认证正确。不得把人工选择称为模型推理或专家结论。尚未自动生成针对公司/行业的沟通方案，那属于后续研究和报告阶段。

9项能力回归覆盖检索不默认认定、精确引用、未确认事实、AI不能直接支持RAG/Python、过期上下文、外部事实ID、缺证不是不会、部分复核与方向反馈范围。HTTP测试验证事实确认变化使旧稿失效。真实Chrome合成测试覆盖生成→失效→再生成→人工复核→方向反馈。

真实资料试跑仅生成草稿：已有简历123条事实与3个现场岗位对照，未自动作任何正向判断，未对全部片段人工复核。原始简历、引用、报告及偏好只保存在本机私有目录，不上传公开仓库。不能把草稿数量当匹配成功数。
