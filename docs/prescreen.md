# 真实岗位条件预筛

main开发能力，尚未进入已发布合成实验包。仅做披露条件判断，不判断职业能力、岗位真实性、公司成长或最终推荐。

## 使用

```text
python scripts/prescreen_jobs.py --checkpoint 自己的采集checkpoint.json --policy examples/prescreen-policy.json --output data/private-market/prescreen-v001.json
```

先复制并明确修改策略；示例不是对所有用户自动套用。支持城市、salaryMinK及必须明确的salaryBasis、必须双休、本人学历。salaryBasis的fixed比较明确底薪/固定月薪；published-lower-bound比较招聘区间下限，两者不等价。未配置的条件不判断，自由文本条件暂不自动转成规则。

网页：以--workspace启动本地工作区，打开简历记录，在“真实岗位条件预筛”选择采集JSON并确认结构化口径后保存。文件上限9MB，超过需等待后续分批导入，不截断冒充完整覆盖。结果只保存本地，历史报告不覆盖，可刷新重载；未集成网页自动采集按钮。

## 结果与证据

三组：披露条件满足、值得核实、明确存在取舍。内部状态分别为disclosed-match、unknown、conflict、disclosed-mismatch。任何明确不符进取舍；无明确不符但存在未知/冲突进核实。披露符合不代表招聘方已承诺，更不代表能力匹配。

证据保留原文精确片段、字符位置、全文hash、URL及采集时间。只从本岗位标题摘要/职位描述取岗位字段，福利仅取同companyKey对应公司页“工作时间及福利”片段，不借推荐岗位/注册地址；身份与URL不一致或重复ID拒绝导入。

- 发布区间不自动视为固定底薪；固定构成未知时保留未知，区间上限已低于底线单独标披露不符。
- 头部/正文薪资不同标冲突；年薪/日薪不自动换算；绩效/试用等限定附近的固定数值不直接确认。
- 不加班不是双休；单/大小/单双/排班与双休并存时标冲突；客户/其他岗位的休息不作为本岗福利。
- 本科标签高于本人学历先核实，不直接当正文硬门槛；明确必须与优先分别处理。
- 地点摘要与正文办公地址/驻点分开，出差/多地需核实；没有可靠定位时未知，不猜公司总部。

公司按平台ID汇总多个岗位，匿名记录单独保留；覆盖数量按当前输入实际统计，目标缺失标未附，不能从coverage-reached字样推断完成100家。reasonCounts是多标签障碍统计，可重叠，不能相加为独立公司数。

这是保守规则解析，仍可能漏读或误读复杂否定、跨段条件、特殊学历及罕见城市地址；不保证中文语义全覆盖。当前地点正文辅助识别仅有限城市列表，不认识的保留未知。重点推荐前必须人工复核，并抽查未入选岗位，不能以分组自动执行投递。

## 验证

17项规则回归包括固定/区间分离、薪资冲突、负面双休、客户福利、学历优先/硬门槛、地点驻点、精确引文、主体隔离与重复ID拒绝。网页HTTP及真实Chrome合成测试覆盖口径明确确认、保存和重载。

已对本机小批3岗位现场快照试跑，结果0披露满足、2待核实、1明确取舍；人工核对了主要薪资/休息/学历/地点引文。该样本既不是全市场也不是推荐清单，未完成100家专家深评。真实报告/原文只留本地，不进入仓库。
