# 本地真实简历工作区

main开发能力，尚未纳入既有合成实验Release。仅本机运行，没有模型、岗位采集、财报查询或投递。

## 启动

需要Python 3.10+。PDF另需在自己的环境按requirements-resume.txt安装pypdf；DOCX/TXT/JSON无第三方解析依赖。

Windows在项目根目录：

```text
start-windows.bat --workspace
```

macOS终端：

```sh
sh ./start-macos.command --workspace
```

直接命令：`python scripts/workspace_server.py`（macOS使用python3）。默认前者从8765、后者从8875尝试20个本机端口。可指定`--no-browser`、`--port`、`--data`；地址由终端输出，Ctrl+C停止。默认数据位置data/private-web，不随停止或刷新清空。macOS新工作区未实机回归，旧合成页通过不能自动继承。

## 页面操作

1. 填写必须、偏好、不在意，每行一个条件；当前保存文本，不自动解析、打分或执行筛选。
2. 选择自己的PDF/DOCX/UTF-8 TXT/JSON并导入；原文件留在本地。JSON需符合experiences格式，TXT不推断公司/职位。
3. PDF/DOCX按页/段展示文字；请另开本地原文件视觉对照，复杂版式/字体可能缺失。扫描件无OCR，不能直接确认成有效履历。
4. 添加工作/教育经历。每个字段选择原文单元、粘贴精确片段，点击加入引用；跨页可以多个引用。错误引用可移除；不凭空填公司、时间、业绩。
5. 勾选已核对字段与条件，再保存新版本。保留历史版本文件，界面当前仅打开最新版本；不覆盖旧输入。
6. 勾选确已核对的事实，点击确认。没有默认全选；本人确认不等于独立核实。TXT/JSON可直接进入事实审阅，也可保存新的条件版本；正文修正目前应重新导入新记录。
7. 刷新记录列表、选择ID打开，可恢复最新版本与确认状态。界面没有删除按钮/加密/多用户权限，不要将共享电脑作为无保护简历库。

## 数据与访问边界

原文、映射、条件、版本、事实盐均在选择的数据目录，默认被Git忽略。源码白名单不包含这些数据。无API下载日志、无遥测、不调用外部模型；第8节经明确确认可请求固定官方财报文档，不发送简历。使用边界见[公司研究](company-research.md)。服务不提供任意文件目录浏览。

仅绑定127.0.0.1，检查Host、来源及每次启动的随机令牌，API不设置跨域许可；页面禁缓存、禁止嵌入。令牌不打印、不放URL、不持久化。其他本机用户/进程若有文件权限仍可能访问资料，这不是账户隔离或恶意文件沙箱。仅导入自己信任的文档，不开放公网，不同时启动多个写入同一数据目录的实例。

导入失败可能仍保留原文件与失败记录，本地保存不代表加密。停止服务后可自行备份/管理私有目录，分享前不要打包整个目录。此前“演示页内存日志”的描述不适用于本工作区。

## 验证

`python scripts/test_workspace_server.py`检查导入/版本/事实确认/重载、DOCX映射、未授权API、Host/Origin拒绝、路径隔离。已用无头Chrome真实DOM测试TXT、DOCX链路，不代表完整人工易用性或macOS实机通过。

可选浏览器测试（Node 18+，已装Chrome，不下载浏览器）：设置DAGONGREN_TEST_PYTHON为解释器、DAGONGREN_TEST_CHROME为Chrome可执行路径后运行`node scripts/test_workspace_browser.mjs`。只用合成数据，独立配置和产物位于data/test-tmp。无头自动化不操作日常浏览器、不占鼠标键盘。
